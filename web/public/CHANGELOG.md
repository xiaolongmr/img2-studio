# 更新记录

> 说明：本文件记录 `img2-studio` 的功能迭代，页面 `/changelog` 会实时渲染这里的内容。

## 2026-05-27

### ✨ 新增
- 新增「提示词库」页面，支持内置 JSON 提示词浏览、搜索、筛选、收藏、详情弹窗、一键使用。
- 新增「自定义提示词」能力，支持本地新增/编辑，并可上传预览图（本地 Base64）。
- 新增「更新记录」页面 `/changelog`，直接读取并渲染本地 `CHANGELOG.md`。
- 侧边栏导航新增「提示词库」「更新记录」入口。

### 🧰 交互优化
- 提示词库支持按模式（全部/生成/编辑）、分类、子分类、来源（内置/自定义）、收藏状态联合筛选。
- 提示词库卡片改为更高密度网格展示，支持悬浮动效、返回顶部按钮、滚动加载更多。
- 提示词详情弹窗支持「复制提示词」与「使用提示词」双入口，减少来回切页成本。
- 图片工作台会话详情渲染策略优化：进入页面与切换会话时优先保证首屏可交互。

### 🧪 稳定性与兼容性
- 图片工作台路由改为懒加载，减少跨页面跳转阻塞。
- 历史会话详情改为延后挂载，降低大体量会话切换卡顿。
- 修复图片接口响应解析中的空值访问问题：`config.storage` 缺失时不再抛错。
- 修复引用插入场景中的光标定位兼容细节，减少误覆盖。
- 统一「图片工作台 / 提示词库 / 设置」等页面文案与导航一致性。
